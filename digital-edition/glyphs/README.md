# Repositório de espécimes de glifos

Ainda NÃO existem espécimes de glifos revisados e aprovados.

Para adicionar: elaborar um JSON de anotações com ID, canvas/page_id,
região de pixels x/y/w/h, candidato de identificação, linha, revisores
e status. O script scripts/glyph_extract.py verifica se a região cabe
na imagem original e produz recortes do serviço institucional IIIF.

Preservar registros mesmo para leituras rejeitadas. Não cometer contornos
de fontes existentes sem licença nem usar formas geradas como verdade.
