# Estudos e resultados

Códigos em src/ ou experiments/. Dados experimentais pequenos e verificáveis
em experiments/runs/AAAA-MM-DD-HNNN-runNN.json, com schema: commit SHA,
entrada SHA-256, parâmetros, sementes, descrição de controle, p/IC, resultado,
limitações e revisão. Resultados negativos NÃO são descartados.

Saídas temporárias do CI em results/tmp e artefatos GitHub expiram: depositar
resultados confirmados com snapshots imutáveis e, futuramente, DOI/Zenodo.
