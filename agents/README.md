# Laboratório multiagente

1. agents/backlog contém tarefas com objetivos mensuráveis.
2. agents/new_fronts contém ideias a testar por outros agentes.
3. agents/TEMPLATE.md determina formato do handoff.
4. hypotheses/HNNN.md define problemas persistentes e critérios de refutação.
5. experiments/runs arquiva resultados com hash/código e revisão.

Estados: IDEA, READY, RUNNING, BLOCKED, REPLICATED, NEGATIVE e REFUTED.
Nenhum estado é atualizado sem execução real e evidência correspondente.
