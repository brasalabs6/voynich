# Registro de novas frentes de pesquisa

Sempre que surgirem novas hipóteses, métodos, controles ou anomalias,
criar arquivo AAAA-MM-DD-HNNN-slug.md usando agents/TEMPLATE.md. Cada
arquivo deve registrar estado PLANNED até existir resultado demonstrável.
Ligar a issue e a hipótese, registrar data, prioridade, valor de informação,
custo, potenciais falsificadores e risco de enviesamento.

Não misturar estudos realizados com ideias não testadas.
