# Plano de primeiras 24h e horizonte plurianual

Este é um plano de trabalho, NÃO uma alegação de investigação contínua já
realizada. Agentes e CI podem executar tarefas explícitas; o ChatGPT desta
conversa não mantém pensamento ativo fora das interações.

| Intervalo planejado | Entrega e critério de conclusão |
|---|---|
| 0–4 horas | PDF íntegro verificado, release, SHA-256 e fontes ZL/IT |
| 4–8 horas | Testes unitários, métricas básicas, diferenças por transcrição |
| 8–12 horas | A/B com controles de quire, mão e página |
| 12–16 horas | Efeitos de posição de linha, alternativas de segmentação |
| 16–20 horas | Modelos negativos: Markov, gerador autocitação, cifra |
| 20–24 horas | Revisão adversarial, limites, registro de novas frentes |

Nenhuma etapa fica CONCLUÍDA até código + dados + resultados verificáveis
estarem preservados. O pipeline semanal do GitHub CI executa apenas os
testes automatizados implementados, NÃO pesquisa criativa autônoma.

Próximas semanas: parser IVTFF completo e comparação com IVTT; controles
cronológicos, modelos generativos e geradores de cifra; catálogo IIIF
com anotação dupla; avaliação cega de rótulos.

Próximos anos: edições críticas, estudo de glifos por imagens, conjunto
de teste congelado por quire, estudos multidisciplinares revisados,
depósitos científicos com DOI e backups redundantes.
